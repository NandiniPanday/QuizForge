# QuizForge

QuizForge is an interactive quiz application developed using Java. The project allows users to attempt quizzes, calculate scores, and improve technical knowledge through a simple and user-friendly interface.

# Features
- Multiple-choice quiz system
- Score calculation
- Simple and interactive UI
- Beginner-friendly application structure
- Timer functionality

# Tech Stack
- Java
- Swing / AWT
- NetBeans

# Future Improvements
- Database integration
- User authentication
- Leaderboard system
